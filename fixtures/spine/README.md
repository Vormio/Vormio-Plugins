# Spine 测试素材

**来源**：全部是本仓库原创，由 [`scripts/fixtures/spine.ts`](../../scripts/fixtures/spine.ts) 程序生成，不含任何 Spine 官方示例或其他第三方内容，也不是 Spine 编辑器的真实导出。

- 骨骼 JSON、图集文本和贴图页 PNG 依据 Esoteric Software 公开的格式说明写成。`preview/` 以外的是结构样本，覆盖分析器读取的内容；贴图页是纯色块加白色的上、左边线，用来检查图集缩略图与查看器的颜色和比例。
- `preview/` 中的骨骼是给 Spine 插件的骨骼缩略图与查看器渲染的小人偶，有 JSON 与二进制两种形式。JSON 依据公开的格式说明写成；二进制骨骼（`.skel`）由 [`scripts/fixtures/spine-binary.ts`](../../scripts/fixtures/spine-binary.ts) 写出。公开的二进制格式说明还是 3.8 的布局，这个脚本按 Spine Runtimes（spine-ts 3.8 的 `28727aff`，spine-core 4.0.31、4.1.56、4.2.120 与 4.3.13）的读取器写成，因此**脚本本身受 Spine Runtimes 许可协议约束**；它只在生成素材时使用，不进入任何插件包。

**许可证**：素材与本仓库相同（MIT，见 [LICENSE](../../LICENSE)）；生成它们的 `spine-binary.ts` 见上。

重新生成（结果会覆盖除本说明外的全部文件，每次结果相同）：

```bash
pnpm run fixtures spine
```
