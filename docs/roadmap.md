# 插件规划

插件能力跟随宿主路线图：只有当提供对应扩展点的 Vormio-Core 版本正在进行或已经完成时，才开始相应的插件能力。

| 插件  | 与 Core 版本的对应             | 能力                                                                                                                                                                     | 状态                           |
| ----- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------ |
| glTF  | Core 0.0.2 起                  | 缩略图；查看器（旋转、缩放、取景，通过配套读取显示贴图）                                                                                                                 | 已完成                         |
|       | Core 0.0.3 起                  | 分析器：列出 bin、贴图、网格、材质与引用状态                                                                                                                             | 已完成                         |
| Spine | Core 0.0.3 起                  | 0.1.0 图集分析器：页面、区域与贴图页引用                                                                                                                                 | 已通过 Core `0b1b59c` 手工验收 |
|       | Core 0.0.3 起                  | 0.2.0 图集缩略图与查看器：第一页贴图；贴图页上的区域框，可以搜索与定位                                                                                                   | 已通过 Core `0b1b59c` 手工验收 |
|       | Core 0.0.3 起                  | 0.3.0 二进制骨骼（`.skel`，Spine 3.8 与 4.0 至 4.3）的缩略图（初始姿势）与查看器（皮肤、动画），用 spine-ts 渲染；从这个版本起每个使用者都需要自己的 Spine Editor 许可证 | 已实现，待 Core 手工验收       |
|       | Core 0.0.6（分析器按内容拒绝） | 0.4.0 骨骼 JSON 分析器（解析已在 0.1.0 中完成，未声明）                                                                                                                  | 等 Core                        |
|       | 缩略图与查看器支持按内容拒绝后 | 0.5.0 骨骼 JSON 的缩略图与查看器                                                                                                                                         | 等 Core                        |

Spine 的设计与后续版本见 [设计计划](plans/spine.md)。

**官方插件目录**（Core 0.0.5 起）：受邀测试者从 Vormio 的插件窗口安装、更新与回滚已经验收的官方插件。2026-10-14 第一次发布（序号 1）：glTF 0.2.0 与 Spine 0.2.0，来自 `982215d`（合并前是 `8eb019b`，内容相同）；当时本仓库还在用 SDK 0.0.3，目录由 Core 构建的 SDK 签名。换用 SDK 0.0.5 之后，发布配置 `release.json` 与命令 `pnpm run catalog` 都在本仓库，见[开发说明](development.md#发布官方目录)；域名、上传凭据与签名私钥不进仓库。下一次发布会把 Spine 换成 0.3.0：要等它通过 Core 手工验收，并决定目录如何展示它的许可要求（[Spine 设计计划](plans/spine.md)待确认的问题 3）。

glTF 是宿主组成与关系契约的第一个真实使用方。其他格式（压缩纹理、PSD、音频、字体、Blender 等）等 glTF 跑通主线后，再按真实需求逐个加入；上一版插件实现可以参考，但不直接搬运。

## 目录规划

目录在真正有内容时才创建。`shared/` 随第二个插件建立，结构见 [开发说明](development.md#目录结构)。`docs/plans/` 存放进行中的插件设计计划；计划完成后，结论写进插件 README，计划移出仓库。
