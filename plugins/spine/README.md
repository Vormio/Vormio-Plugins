# Spine 骨骼动画

插件 ID `vormio-plugins.spine`，版本 0.3.0。

- **二进制骨骼（`.skel`）**：缩略图显示初始姿势，查看器可以切换皮肤、播放动画。渲染使用 Esoteric Software 的官方运行时 spine-ts。
- **纹理图集（`.atlas`，Spine 与 libGDX）**：缩略图显示第一页贴图，查看器在贴图页上画出区域框，可以搜索和定位区域；组成分析列出页面与区域，以及每个页面引用的贴图文件。

> **许可要求**：插件包含 Spine Runtimes，按 Spine Runtimes 许可协议分发，**每个使用者都需要自己的 Spine Editor 许可证**，只用图集查看与组成分析也一样：许可协议约束的是包含运行时的整个插件。分发方不持有 Spine Editor 许可证；插件无法核实使用者是否持有。每个运行时的协议原文随插件包附在 `licenses/SPINE-RUNTIMES-<版本>.txt`（4.0 与 4.1 带的是 2019 年版，4.2 与 4.3 带的是 2025 年版，条款相同）。

- **宿主**：Vormio-Core 0.0.3 起（插件契约 `apiVersion: 1`，缩略图、查看器与分析器扩展点）。SDK 使用 [`vendor/`](../../vendor/README.md) 中固定的 0.0.5 打包产物。
- **不修改任何文件**：骨骼的缩略图与查看器读取骨骼、同一目录中的同名图集与图集的贴图页；图集的缩略图与查看器读取图集与它的 PNG、JPEG 贴图页；分析器只读取图集本身。
- 从 0.2.0 升级时新增了骨骼的缩略图与查看器，权限指纹改变，需要在资源库中重新启用；许可要求也从这个版本开始。从 0.1.0 升级时新增了图集的缩略图与查看器，同样需要重新启用。
- 设计与后续版本见 [设计计划](../../docs/plans/spine.md)。

## 支持的格式与版本

| 文件     | 版本                                                                                                                                  |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `.skel`  | Spine 4.0 至 4.3 导出的二进制骨骼，分别由同一主次版本的 spine-ts 读取；图集是同一目录中同名的 `.atlas`（`hero.skel` → `hero.atlas`）  |
| `.atlas` | Spine 4.x 的写法（区域用 `bounds`、`offsets`，页面可有 `pma`、`scale`）与 Spine 3.x / libGDX 的写法（`xy`、`size`、`orig`、`offset`） |

运行时只读取与自己主次版本相同的数据，所以插件先从骨骼的文件头读出版本，再加载对应的运行时；每个运行时各是一个分块，只在显示这个版本的骨骼时加载，图集的页面不加载运行时。其他版本（例如 3.8、5.0）显示原因，例如“Spine 5.0.00 的数据：插件只包含这些版本的运行时：4.0、4.1、4.2、4.3。”

图集文本按 UTF-8 读取，可以有 BOM，换行可以是 LF 或 CRLF。

骨骼 JSON（Spine 3.8 至 4.2）的解析已经完成并有测试，但**这个版本没有声明 `json`**：宿主只按扩展名选择插件，声明后库中每个 JSON 文件都会被当作 Spine 分析、由这个插件生成缩略图并取代文本预览。等宿主支持按内容拒绝文件后再声明（设计计划 §8 R1）。

## 能力

### 骨骼

**缩略图**：初始姿势，默认皮肤；默认皮肤在初始姿势下没有可见附件时，用第一个有可见附件的皮肤。按可见部分的范围取景，留出很小的边距，最长边是宿主给出的大小（目前 320 px），背景透明。物理约束不模拟。

**查看器**：

- 打开时播放第一段动画并循环，与 Spine 自己的播放器相同；没有动画的骨骼显示初始姿势。
- 工具栏：皮肤（多于一个时显示）、动画（含“初始姿势”）、播放与暂停（空格）、循环、速度（0.25× 至 2×）、适应（F）。
- 拖动平移，滚轮以光标为中心缩放。取景包含所选动画整个过程中的范围；切换皮肤或动画时重新取景，除非已经手动平移或缩放过。
- 底部：Spine 版本、骨骼与插槽数量、当前动画的时间，以及许可说明。
- 读不到的贴图页不中止显示：用到它的附件不画，左上角说明原因，例如“贴图页无法读取，用到它的附件不显示：torn.png（文件不存在）”。
- 浅色与深色主题跟随系统；换文件时释放上一份骨骼的贴图。

**失败的原因**（缩略图失败时宿主显示类型图标与原因；查看器向宿主报告）：

- 找不到同名图集，例如“找不到同名图集 orphan.atlas（文件不存在）”。
- 贴图页读不到（只有缩略图失败，查看器照常显示）。
- 文件开头没有 Spine 版本，或版本没有对应的运行时。
- 运行时无法读取数据，例如文件被截断：“Spine 运行时无法读取这个骨骼：…”，后半句是运行时的原文。
- 初始姿势下没有可见的附件（只有缩略图失败）。

### 图集

**缩略图**：第一张能读到的贴图页，按比例缩放到宿主给出的最长边（目前 320 px），背景透明。放大的小贴图保持像素清晰，缩小的平滑处理。前面的页面读不到时用后面的；所有页面都读不到时缩略图失败，宿主显示类型图标，并说明原因，例如“贴图页都无法显示：absent.png（文件不存在）”。

**查看器**：在贴图页上画出区域框，右侧列出区域。

- 拖动平移，滚轮以光标为中心缩放；“适应”（F）让整页回到视野中；“区域框”（B）显示或隐藏区域框。
- 悬停或点击区域显示它的名称、旋转前的尺寸、在页面上的位置与旋转角度；双击放大到这个区域。旋转 90° 的区域在页面上占用的宽高互换，区域框按实际占用画出。
- 区域列表可以按名称搜索（最多列出 1,000 个，其余可以搜索到）；点击区域会切到它所在的页面，放大并高亮。多页图集可以在工具栏选择页面，页面贴图在第一次显示时才读取。
- 贴图页读不到时仍显示区域框与页面大小（来自 `size`，没有时按区域的范围），并在左上角说明原因，例如“贴图页无法显示，只显示区域框：absent.png（文件不存在）”。
- 浅色与深色主题跟随系统；查看区较窄时隐藏区域列表。
- 换文件时释放上一份图集的贴图；不是图集的文本向宿主报告原因。

**组成分析**：宿主在后台调用分析器，结果显示在详情栏的“组成”区与贴图文件的“被引用”区。

- **子资源**：

  | 类别 | `key`            | 名称                                          | 上级     |
  | ---- | ---------------- | --------------------------------------------- | -------- |
  | 页面 | `pages/<序号>`   | 页面行写的图片文件名，原样显示                | —        |
  | 区域 | `regions/<序号>` | 区域名；`index` 不小于 0 时写成“名称（帧 N）” | 所在页面 |

- **文件引用**：每个页面引用它的图片，角色“贴图页”，证据为“第 N 行”。由宿主相对图集文件解析，可以带子目录与 `../`。图集里写的是文件名而不是 URI，所以文件名中的 `%`、`?`、`#` 会编码成 `%25`、`%3F`、`%23` 后报告，宿主解码后得到原来的文件名；其他字符（包括空格）原样报告。
- **诊断**：
  - 同一图集中名称与 `index` 都相同的区域：警告。Spine 按名称在整个图集中查找区域，只会用到第一个。
  - 没有位置（`bounds` 或 `xy`）的区域、数字个数或格式不对的字段：警告。
  - 无法识别的页面字段，以及第一个页面之前的字段：信息。区域中的其他字段是 Spine 的“名称/值”附加数据，不报告。
  - 超过 2,048 个字符的页面文件名：警告，这个页面不报告引用。
- **上限**：子资源超过 10,000 个或报告超过 4 MiB 时，保留全部页面与页面引用，从最后的区域开始略去，报告标为部分完成并附说明。名称去掉控制字符，按 200 个字符截断。
- **失败**：
  - 不是图集文本，即页面名之后不是页面字段，例如“不是 Spine 或 libGDX 图集：第 1 行的页面名后面应当是页面字段（例如 size: 1024, 512）。”
  - 没有任何页面。
  - 文件读不到或已经变化。

分析器不声明 `companionFormats`，因为它从不读取配套文件。图集的三个页面打包后共约 20 KB，不加载 Spine 运行时。

## 声明的权限

- 骨骼的缩略图与查看器：`formats: skel`，`companionFormats: atlas, png, jpg, jpeg`。
- 图集的缩略图与查看器：`formats: atlas`，`companionFormats: png, jpg, jpeg`（Spine 打包器输出的贴图页格式）。
- 分析器：`formats: atlas`，没有配套格式。

增减其中任何一项都会改变权限指纹，用户需要重新启用。

## 不支持的情况

- JSON 骨骼的分析、缩略图与查看器：暂不声明（见上）。二进制 `.skel` 的组成分析：不支持。
- 骨骼预览只按同名约定查找图集：图集另起名字、多个骨骼共用一个图集时找不到。
- Spine 4.2 之前与 4.3 之后的骨骼数据。
- 骨骼预览中的事件音频、调试绘制（骨骼、包围盒、路径）与按插槽的显示开关。
- 启用前确认许可：宿主还不支持（设计计划 §8 R4），要求写在插件说明、本文与骨骼查看器中。
- 骨骼与图集的同名配对（`hero.json` ↔ `hero.atlas`）不报告为引用：它是约定，文件中没有地址（设计计划 §8 R2）。
- 区域与使用它的附件之间的关系：目前的契约不能引用另一个文件中的子资源（设计计划 §8 R3）。
- PNG 与 JPEG 以外的贴图页（例如 WebP、KTX2）：宿主拒绝读取；图集查看器只显示区域框，骨骼按“读不到的贴图页”处理。
- 图集查看器不显示预乘 alpha（`pma`）的校正、去白边前的原始尺寸（`offsets`、`orig`）与九宫格（`split`、`pad`）。骨骼预览由运行时按 `pma` 绘制。

## 骨骼解析（已实现，未声明）

`src/skeleton.ts` 解析 Spine 3.8 至 4.2 的骨骼 JSON。识别条件：顶层是对象，有 `skeleton.spine` 版本字符串与 `bones` 数组；不满足时抛出 `NotSpineError`，宿主支持拒绝后就用它作为“不是我的格式”。

- **子资源**：骨骼（按父骨骼显示层级）、插槽、IK 约束、变换约束、路径约束、物理约束（4.2）、皮肤、附件（上级为皮肤，类别细分为区域、网格、链接网格、包围盒、路径、点、裁剪附件）、事件、动画。附件名称是附件键；查找区域用的名字（`path` 或 `name`）不同时写成“head（区域 head-front）”，序列附件写成“head-blink（区域 head-blink，3 帧）”。事件有音频时写成“footstep（音频 footstep.wav）”。
- **内部引用**：
  - 插槽 → 所在骨骼、初始附件（默认皮肤中的）。
  - 约束 → 约束骨骼、约束目标（路径约束的目标是插槽）。
  - 皮肤 → 皮肤专属的骨骼与约束。
  - 附件 → 所在插槽；链接网格 → 父网格（可以在其他皮肤）；裁剪附件 → 结束插槽。
  - 动画 → 骨骼、插槽、约束、事件与附件。附件来自 3.8/4.0 的 `deform` 时间轴，或 4.1 起的 `attachments` 时间轴；`drawOrder` 中的插槽也算。
  - 同一对象之间同一角色的引用只报告一次。证据是 JSON 指针。
- **文件引用**：没有。`skeleton.images`、`skeleton.audio` 与事件音频的路径基准还没有用真实导出确认。
- **诊断**：引用的名称不存在（引用略去）、同名对象（按名称引用时只会找到第一个）、骨骼层级成环（断开一处）、无法识别的附件类型、结构不对的部分（报告标为部分完成）、比 4.2 新的版本。
- **失败**：3.7 及更早的版本（包括 `skins` 是对象而不是数组的文件）。
- **上限**：超出时按附件、动画、物理/路径/变换/IK 约束、事件、皮肤、插槽、骨骼的顺序，从最后一个开始略去。

## 构建、开发与测试

在仓库根目录运行（准备工作见仓库 README）：

```bash
pnpm run build spine
```

输出到 `dist/spine/`，可以在 Vormio 的“插件”页作为开发目录添加；`pnpm run dev spine` 会在源码变化时更新它。

```bash
pnpm run package spine
```

生成 `artifacts/vormio-plugins.spine-0.3.0.vormioplugin`。
